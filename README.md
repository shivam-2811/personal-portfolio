🎧 About The Project
A responsive, interactive personal portfolio designed to mimic the aesthetic and functionality of the Spotify desktop app. This project was built from scratch using pure HTML, CSS, and Vanilla JavaScript to showcase my technical projects, skills, and hobbies in a creative and engaging format.

✨ Key Features
Custom Audio Player: A fully functional "Now Playing" footer bar with a working play/pause button, live progress bar, and hidden HTML5 audio integration.

Dynamic Greetings: JavaScript-powered headers that automatically update to "Good morning," "Good afternoon," or "Good evening" based on the user's local time.

Modern CSS Layouts: Utilizes CSS Grid and Flexbox to recreate Spotify's signature card layouts and pill-shaped filter tags.

Fully Responsive: Adapts seamlessly to both desktop monitors and mobile screens without breaking the custom audio footer.

Dark Theme UI: Strictly adheres to Spotify's color palette (deep blacks, dark greys, and the signature #1ed760 accent green).

🚀 How to Run Locally
Clone this repository or download the ZIP file.

Ensure index.html, style.css, your profile image (SHIVAM.jpg), and your background music file (song.mp3) are in the same root folder.

Open index.html in any modern web browser to view the site.
